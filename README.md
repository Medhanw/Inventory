# Inventory Management App

## Project Overview

The Inventory Management App is an Android application developed using Kotlin and Jetpack Compose to help users manage and organize inventory records efficiently.

The application allows users to store, update, and manage inventory details through a simple and user-friendly interface while demonstrating database integration and Android application development concepts.

---

## Features

- Add and manage inventory items
- Update product information
- Delete inventory records
- Database integration for data storage
- User-friendly Android interface
- Modern UI using Jetpack Compose
- Efficient inventory tracking system

---

## Technologies Used

- Kotlin
- Jetpack Compose
- Android Studio
- SQLite / Room Database
- Material Design
- Git & GitHub

---

## Project Working

1. Users can add inventory items with relevant details.
2. The application stores product information in the database.
3. Users can update or delete records whenever required.
4. Inventory data is displayed dynamically through the Android user interface.

---

## Installation and Setup

Clone the repository:

```bash
git clone https://github.com/Medhanw/Inventory.git
```

Open the project in Android Studio.

Build and run the application on an Android Emulator or physical device.
